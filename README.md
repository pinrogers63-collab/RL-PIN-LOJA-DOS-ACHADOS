# RL PIN - Loja dos Achados V5 Premium

Base oficial do projeto RL PIN, separada do NOVYXPRIME.

## Objetivo
Construir uma central premium para:
- garimpo diário de produtos;
- deduplicação e atualização;
- cálculo de margem e preço recomendado;
- Guardião RL de conformidade;
- Salão com imagens/copy;
- persona Vitória em vídeo curto;
- fornecedores, estoque e SLA;
- conectores para Shopee, Mercado Livre, TikTok Shop e Pinterest;
- futuras plataformas.

## Janelas planejadas
- 06:00: garimpo principal
- 10:00: atualização de preço/estoque
- 15:00: checagem final do dia

Integrações externas só serão marcadas como conectadas quando houver credenciais e validação reais.
